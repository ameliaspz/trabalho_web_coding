🌐 Tim Berners-Lee e a Criação da Web

Projeto desenvolvido para a disciplina de Web Coding — 2º período, apresentando a história da criação da World Wide Web, desde as ideias que antecederam sua criação até a evolução das tecnologias utilizadas atualmente.

📖 Sobre o projeto

Este projeto apresenta a história da World Wide Web e o papel de Tim Berners-Lee em sua criação.
A página aborda o contexto existente antes da Web, o conceito de hipertexto e alguns dos principais acontecimentos que contribuíram para seu desenvolvimento.
Também é apresentada a evolução das tecnologias utilizadas na construção de páginas, desde o HTML original até o HTML5, além do surgimento e evolução do CSS até o CSS3.

🕒 Linha do tempo

O projeto apresenta alguns dos principais acontecimentos relacionados à criação e evolução da Web:

1945 — O Memex de Vannevar Bush
1965 — Ted Nelson e o conceito de hipertexto
1969 — Nascimento da ARPANET
1980 — ENQUIRE, desenvolvido por Tim Berners-Lee
1989 — Proposta da World Wide Web
1990 — Desenvolvimento do primeiro navegador
1991 — A Web é disponibilizada ao público
1993 — A Web passa a utilizar software livremente disponível
1994 — Fundação do World Wide Web Consortium (W3C)

👨‍💻 Tim Berners-Lee

A página apresenta a participação de Tim Berners-Lee no desenvolvimento da Web e a ideia de criar um sistema capaz de conectar informações por meio de hiperlinks.
A proposta buscava facilitar o compartilhamento e o acesso às informações entre diferentes computadores e sistemas.

💻 Tecnologias utilizadas

O projeto foi desenvolvido utilizando:
HTML5 — utilizado para estruturar e organizar o conteúdo da página.
CSS3 — utilizado para definir o visual, layout, cores, espaçamentos e responsividade.
O projeto não utiliza JavaScript.

Estilo e design

O visual da página foi desenvolvido com uma proposta inspirada em tecnologia e história da Web.

O CSS utiliza:

Fundo em tons escuros;
Cards para organizar as informações;
Cores de destaque em azul;
Bordas arredondadas;
Sombras;
Gradientes;
Efeitos de hover;
Transições;
Variáveis CSS através de :root.
As variáveis CSS foram utilizadas para facilitar a organização e alteração das principais características visuais do projeto.

📱 Responsividade

O projeto possui uma media query para adaptar a página a telas menores.
Em dispositivos com largura de até 640px, alguns elementos são modificados para melhorar a visualização, como:
Redução dos espaçamentos laterais;
Redução do espaçamento entre os elementos;
Ajuste dos cards;
Links do menu ocupando toda a largura disponível;
Centralização dos links.
Dessa forma, a página consegue se adaptar melhor a dispositivos móveis.

📚 Conteúdo abordado

Entre os principais assuntos apresentados na página estão:

- A criação da Web
O contexto tecnológico existente no final da década de 1980 e os problemas relacionados ao acesso e compartilhamento de informações.

- Hipertexto
As ideias que antecederam a criação da Web e contribuíram para o desenvolvimento de um sistema baseado em documentos conectados.

- Evolução da Web
Os principais acontecimentos entre as primeiras ideias de hipertexto e a expansão da World Wide Web.

- HTML5 e CSS3
A evolução das tecnologias responsáveis pela estrutura e apresentação das páginas web.
